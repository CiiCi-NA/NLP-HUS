# NLP Project: Text Tokenization Lab

## 1. Tổng quan

Bài tập này là bài tập đầu tiên môn NLP, tập trung vào bước **tiền xử lý văn bản cơ bản: Tokenization**.  
Mục tiêu là xây dựng các tokenizer đơn giản và nâng cao để phân tách văn bản thành các token (từ, dấu câu, số, v.v.) nhằm phục vụ cho các bước NLP tiếp theo như POS tagging, Named Entity Recognition, hay Machine Translation.
